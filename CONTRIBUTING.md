# Contributing Guidelines

Thank you for your interest in contributing to this project!

## How to Contribute
1. **Fork the Repository**: Create a personal fork on GitHub.
2. **Clone & Branch**:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Commit Conventions**: Follow [Conventional Commits](https://www.conventionalcommits.org/):
   - `feat:` for new capabilities
   - `fix:` for bug fixes
   - `docs:` for documentation updates
   - `test:` for test additions/improvements
4. **Testing**: Ensure all automated test suites pass locally before submitting.
5. **Open a Pull Request**: Provide a clear summary of changes, motivation, and any testing performed.

## Code Quality Standards
- Adhere to project linting and formatting configurations.
- Avoid committing secrets, local environment files (`.env`), or large temporary binaries.
